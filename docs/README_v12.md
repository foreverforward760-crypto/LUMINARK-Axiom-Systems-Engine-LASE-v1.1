## STEP-BY-STEP DEPLOYMENT

### Step 1 — Download your GitHub engine files locally
Go to your GitHub repo and download these two files to a folder on your computer:
- `LatestLUMINARK_OVERWATCH_PRIME_ULTRA.py`
- `LUMINARK_CONSCIOUSNESS_ENGINE_OMEGA.py`

### Step 2 — Run the patch script
Copy `APPLY_LUMINARK_PATCHES.py` into the same folder as the engine files. Then run:
```
python APPLY_LUMINARK_PATCHES.py
```
This will:
- Fix the contact email in both engines
- Inject the Constitutional Directive into both engines
- Add the complete Ω-9 engine to the ULTRA file
- Bump version strings to v12.0
- Create backup files automatically

### Step 3 — Replace your support files
In that same folder, rename/replace:
- `main_v12.py` → `main.py`
- `requirements_v12.txt` → `requirements.txt`
- `Dockerfile_v12` → `Dockerfile`

### Step 4 — Upload everything back to GitHub
Upload all files back to your `Luminark-Ultra` repo using the GitHub web interface (same process as the UPLOAD_INSTRUCTIONS.txt).

### Step 5 — Test locally (optional but recommended)
```
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
```
Then open: http://localhost:8000/docs
